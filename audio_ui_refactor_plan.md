# План обновления управления звуком (VolumePopup)

Мы возвращаем `VolumePopup` для выбора аудиодорожек и громкости, но переносим инструменты обработки звука (шумодав, компрессор и т.д.) непосредственно в интерфейс окна, расположив их слева от списка дорожек. Вкладки будут удалены.

## 1. Рефакторинг VolumePopup (volume_popup.py)
*   **Удаление QTabWidget**: Весь интерфейс теперь будет в одном окне без переключения вкладок.
*   **Новая компоновка (Layout)**:
    *   **Левая панель (DSP Tools)**: Вертикальная колонка кнопок:
        *   `Noise` (Циклическая кнопка: Off -> Standard -> AI)
        *   `Comp` (Checkable)
        *   `Deess` (Checkable)
        *   `Mono` (Checkable)
    *   **Центральная панель**: Список аудиодорожек (`QListWidget`).
    *   **Правая панель**: Вертикальный слайдер громкости.
*   **Удаление лишнего**: Группировка (GroupBoxes), крутилки (SpinBox) задержки и лишние отступы будут убраны для компактности.

## 2. Обновление Player (player.py)
*   **Отказ от кнопок на главной панели**: Удаляем кнопки фильтров и комбобокс дорожек, которые были добавлены в предыдущем шаге.
*   **Возврат VolumeButton**: Возвращаем кнопку вызова `VolumePopup`.
*   **Синхронизация сигналов**:
    *   Подключить новые сигналы кнопок из `VolumePopup` к методам обработки фильтров в `VideoPlayerWidget`.

## 3. Стилизация (dark.qss)
*   Настройка стилей для кнопок фильтров внутри поп-апа, чтобы они выглядели компактно и имели четкую индикацию активного состояния.

## 4. Очистка
*   Удаление неиспользуемых методов и переменных, оставшихся от предыдущего варианта интеграции.
