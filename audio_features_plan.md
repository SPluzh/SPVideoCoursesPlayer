# Профессиональная работа со звуком (Audio Features Plan)

## 1. Обзор
Внедрение комплекта инструментов для обработки звука в реальном времени с использованием фильтров FFmpeg/MPV (`lavfi`).
Цель: Улучшение разборчивости речи в лекциях, устранение фонового шума, выравнивание громкости.

---

## 2. Архитектура

### 2.1 Backend (MPV & Filters)
В `player.py` / `VideoPlayerWidget` будет добавлен класс или набор методов `AudioProcessor` для управления цепочкой аудиофильтров.

**Ключевой метод управления:**
Использование лейблов MPV для независимого включения/выключения фильтров без перезагрузки всей цепочки.
- `af add @noise:lavfi=[...]`
- `af toggle @noise`
- `af remove @noise`

**Список фильтров (приоритет по цепочке):**
1. **Noise Reduction (Шумоподавление)** - *Первый в цепочке*
   - `Standard` (CPU-light): `afftdn=nf=-25`
   - `AI` (RNNoise): `arnndn=m={path_to_model}` (требует файл `bd.rnn`)
2. **De-esser (Устранение свистящих)**
   - `deesser=i=0.4:f=0.5:m=0.5`
3. **Compressor / Normalizer (Выравнивание)**
   - `dynaudnorm=f=75:g=25:p=0.55` (настройки для речи)
4. **Channel Mapping (Стерео/Моно)**
   - `Mono`: `pan=stereo|c0=c0+c1|c1=c0+c1` (сумма каналов в оба уха)
   - `Swap`: `pan=stereo|c0=c1|c1=c0` (обмен каналами)
   - `Normal`: (отключение фильтра панорамирования)

### 2.2 Управление ресурсами (AI Model)
- Файл модели: `resources/bd.rnn`
- Если файл отсутствует:
  - Опция "AI Noise Reduction" в UI будет заблокирована (grayed out).
  - Будет добавлена кнопка/инструкция "Скачать модель" (ссылка на репозиторий Xiph/RNNoise).

## 3. Пользовательский Интерфейс (UI)

### 3.1 Интеграция в VolumePopup
Новые инструменты будут добавлены непосредственно в `VolumePopup` (меню громкости), используя вкладки (`QTabWidget`).

**Вкладка 1: Tracks**
- Стандартный выбор аудиодорожки.
- Слайдер громкости.

**Вкладка 2: DSP / Tools**
1. **Noise Reduction**: ComboBox [Off, Standard, AI].
2. **Speech**: Checkboxes [Compressor, De-esser].
3. **Channels**: Циклическая кнопка или ComboBox [Normal, Mono, Swap].
4. **Delay**: SpinBox для сдвига звука (+/- мс).

### 3.2 (Удалено)
*Секция удалена, так как инструменты интегрированы в основное окно громкости.*

## 4. Горячие клавиши (Hotkeys)

В `hotkeys.py` будут добавлены новые действия:
- `Shift + <` (Shift + Comma): Задержка звука **-50 мс**
- `Shift + >` (Shift + Period): Задержка звука **+50 мс**

Логика:
- Текущая задержка получается через MPV property `audio-delay`.
- Новое значение устанавливается через `input_command`.
- Визуальное отображение (OSD) через `player.show_text()`.
